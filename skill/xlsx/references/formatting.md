# Spreadsheet formatting

Follow existing styles when editing. For new workbooks, use a small style system for titles, headers, inputs, formulas, totals, warnings, and notes. Apply styles by semantic role rather than cell-by-cell exceptions.

Set useful column widths, row heights, freeze panes, filters, number formats, print areas, repeating print titles, orientation, and margins. Avoid excessive merged cells; use them only where they will not obstruct sorting or data entry. Add data validation and conditional formatting when they prevent mistakes or reveal meaningful exceptions.

Use Excel tables for structured datasets when appropriate. Charts need descriptive titles, labeled axes, readable number formats, and source ranges that exclude totals unless intentionally charted. Ensure color is not the only signal.

After styling or charting, follow `/mnt/data/skills/xlsx/references/validation.md`.
