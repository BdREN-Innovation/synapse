# Presentation charts

Choose a chart that matches the comparison: bars for categories, lines for time, scatter plots for relationships, and stacked charts only when part-to-whole changes matter. Avoid 3D effects and redundant legends.

Use native PowerPoint charts when editability is required. Keep the embedded workbook, chart XML, relationships, and content types synchronized. Give each series a stable name, set explicit number formats, and verify category/series ranges. When source data is external, either embed an approved snapshot or preserve the link as requested and disclose it.

Make labels readable and use direct labeling when it reduces lookup effort. Never imply precision unsupported by the source data. After writing, reopen the deck with a second library and follow `/mnt/data/skills/pptx/references/validation.md`.
