# Creating presentations

Use baked-in PptxGenJS for programmatic decks or `python-pptx` when its feature set is sufficient. Set the slide size before placing content and use one unit system consistently.

Outline the narrative before generating slides: purpose, audience, sequence, evidence, and conclusion. Build reusable functions for titles, footers, image placement, and common content blocks. Keep slide IDs, relationships, media, and notes coherent.

Favor native text, shapes, tables, and charts over screenshots so the deck remains editable. Add speaker notes or source citations when requested. Provide alternative text for meaningful visuals when supported.

Write the deck under `/mnt/data/outputs/`, apply `/mnt/data/skills/pptx/references/design.md` as needed, then follow `/mnt/data/skills/pptx/references/validation.md`.
